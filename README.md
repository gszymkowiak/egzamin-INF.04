# Egzamin INF.04 – Projektowanie, programowanie i testowanie aplikacji

Repozytorium zawiera rozwiązania zadań praktycznych przygotowujących do egzaminu zawodowego **INF.04 – Projektowanie, programowanie i testowanie aplikacji**.

## Cel repozytorium

Celem projektu jest:

- gromadzenie rozwiązań zadań egzaminacyjnych z poprzednich sesji,
- prezentowanie przykładowych implementacji w różnych technologiach,
- pomoc uczniom technikum programistycznego w przygotowaniu do egzaminu zawodowego,
- utrwalanie dobrych praktyk programistycznych.

## Zawartość

W repozytorium można znaleźć rozwiązania obejmujące m.in.:

- aplikacje konsolowe,
- aplikacje desktopowe,
- aplikacje webowe,
- aplikacje mobilne,
- zadania związane z algorytmiką,
- operacje na plikach,
- programowanie obiektowe,
- testowanie aplikacji.

## Wymagane środowiska

W zależności od rozwiązania mogą być wymagane:

- Visual Studio 2022+
- .NET 8 lub nowszy
- Node.js
- Android Studio
- Git

## Jak uruchomić projekt

1. Sklonuj repozytorium:

```bash
git clone https://github.com/gszymkowiak/egzamin-INF.04.git
```

2. Przejdź do wybranego katalogu zadania.
3. Otwórz projekt w odpowiednim środowisku programistycznym.
4. Uruchom aplikację zgodnie z dokumentacją znajdującą się w folderze zadania.

## Materiały do nauki

Podczas przygotowań do egzaminu warto ćwiczyć:

- programowanie obiektowe,
- operacje na kolekcjach i tablicach,
- obsługę plików,
- tworzenie interfejsów użytkownika,
- pracę z bazami danych,
- testowanie aplikacji,
- analizę treści arkuszy egzaminacyjnych.

## Współpraca

Jeżeli zauważysz błąd lub chcesz dodać własne rozwiązanie:

1. Utwórz fork repozytorium.
2. Dodaj swoje zmiany.
